# Source notice

This project is derived from the Blender render batch candidate and its supporting [blenderctl](https://github.com/tsist/blenderctl) runtime. The bundled runtime retains the original module notices and is distributed with the corresponding source under GPL-3.0-or-later. The included demo script produces original procedural scenes. Blender and FFmpeg are separate tools supplied by the operator.

The release is scoped to the Blender render batch command, extension, Colab runner, and skill.
